# manage_bot — бот менеджера LevelUp

Связка «сайт → заявка → Telegram менеджеру» + переписка с клиентами в боте.

## Что умеет

1. **Заявки с сайта.** Сайт шлёт POST на `/apply` (через туннель/домен) —
   бот сохраняет заявку и присылает её менеджеру с кнопкой «✅ Обработана».
2. **Статусы.** «✅ Обработана» / «↩️ Вернуть в работу» — пишутся в SQLite
   (`manage_bot.db`), таблица `leads`. Вся история — в файле БД рядом с ботом.
3. **Переписка.** Клиент пишет боту — сообщение пересылается менеджеру
   с кнопкой «✍️ Ответить»; менеджер нажимает и отвечает **чем угодно**:
   текст, фото (с подписью), гиф, стикер, голосовое, кружок, документ.
   Отмена ответа — /cancel.
4. Сообщение из чата тоже становится заявкой (source=chat) и видно в БД.
5. **/leads** — все заявки двумя секциями: «📨 С сайта» и «💬 Из чата».
6. **/roster** — список учеников из БД основного бота LevelUp (имя, предмет,
   доступ до какого числа) + CSV-файл (открывается в Excel/Google Таблицах,
   оттуда экспортируется в PDF).

## Запуск

```bash
cd /Users/weriwq/manage_bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN, MANAGER_TG_ID, WEB_API_KEY
nohup .venv/bin/python -m app.main >> logs/manage_bot.log 2>&1 &
```

- `MANAGER_TG_ID` — узнать у @userinfobot (числовой id вашего Telegram).
- Порт по умолчанию 8081 (переменная `WEB_PORT`).
- Проверка: `curl http://127.0.0.1:8081/health` → `{"ok": true}`.
- Для доступа из интернета (сайт на Vercel и т.п.) — бесплатный туннель:
  `nohup cloudflared tunnel --url http://127.0.0.1:8081 >> logs/tunnel.log 2>&1 &`
  адрес появится в логе (`https://xxx.trycloudflare.com`) — он ВРЕМЕННЫЙ,
  меняется при перезапуске туннеля.

## Форма на сайте

Сайт отправляет POST (form-data или JSON) на `/apply`:

```
X-Api-Key: <WEB_API_KEY из .env>
name: Иван
phone: +375 29 123-45-67
who: ученик            # необязательно
subject: математика    # необязательно
```

Пример на JS:

```js
fetch("https://ВАШ_ТУННЕЛЬ.trycloudflare.com/apply", {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-Api-Key": "..." },
  body: JSON.stringify({ name, phone, who, subject }),
});
```

Ответ: `{"ok": true, "id": 5}` — бот тут же присылает заявку менеджеру.
